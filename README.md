# **ObservableUniverse**

**ObservableUniverse** es un proyecto en Unity enfocado en experimentar con efectos visuales (VFX), iluminación y composición artística inspirada en la estética de escalas físicas extremas en este caso es una representación del universo observable compuesto de VFX Graph y Shadergraph.

## Puesta en marcha
1. Abre el proyecto con la versión de Unity indicada en `ProjectSettings/ProjectVersion.txt`.
2. Carga la escena principal en `Assets/3-Scenes/ObservableUniverse.unity`.
3. Ejecuta el proyecto desde el editor para validar materiales, luces y VFX.

## Requisitos

* Unity **6000.3.10f1**
* Render Pipeline: Universal Render Pipeline (URP)
* Paquetes: Visual Effect Graph

## Contenido

* **VFX Graph:** `OuterRing`
* **Shader Graph:** `Outeruniverseshader`, `Universe BG`, `Universe BG 1`, `Universe Mid`, `UniverseShader`
* **Prefabs:** `Observable Universe_1`, `Observable Universe_2`, `ObservableUniverse`
* **Escenas:** `Assets/3-Scenes/ObservableUniverse.unity`

## Uso

1. Clona el repositorio y añádelo en Unity Hub (*Add project from disk*).
2. Ábrelo con Unity **6000.3.10f1**.
3. Abre la escena `Assets/3-Scenes/ObservableUniverse.unity` y pulsa **Play**.
